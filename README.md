# Delta Neural Operator (DNO)

**Carlo Young** · **DNO 1.0 research series** · **Apache License 2.0**

> **Beyond Conventional Neural Computation — Exploring a New Frontier in AI Architecture**
>
> **What if neural computation could transform its own effective structure through interaction?**
>
> DNO is an open-source, trainable experimental neural architecture exploring evolving effective states, relatively autonomous computational carriers, and history-dependent interactions. Rather than treating every transformation as a separately predefined algorithmic category, it investigates how shared learnable dynamics and executed interactions can reshape the structures that condition future computation.
>
> **Explore the core. Run the experiments. Test what comes next.**

**Research positioning:** DNO explores alternative foundations for neural computation. “Beyond conventional” describes the research direction, **not** a demonstrated performance advantage over Transformers or commercial LLMs. DNO is not a pretrained language model; broader comparative evaluation remains future work.

---

Delta Neural Operator is a trainable neural computation architecture based on effective current state, shared generative dynamics, and interactions among relatively autonomous computational carriers. A state incorporates the effective consequences of earlier interactions and conditions what can happen next. Interactions may modify their participants, create further carriers, and thereby change subsequent interactions.

Observation may occur, change, or remain absent. State evolution does not require an observation on every step. Conditional future states are described by the current state and the operations that can be applied; no catalog of all future outcomes is needed.

## Run and verify

```bash
python -m pip install -r requirements.txt
python -m pip install -r requirements_research.txt
python -m pytest -q -p no:cacheprovider tests/test_final.py tests/test_modal_interfaces.py research_tests
python demo.py
python verify_distribution.py
```

To reproduce training without overwriting the included checkpoints:

```bash
python train_synthetic.py --pair-steps 450 --history-steps 350 --out /tmp/dno-training-run
```

`verify_checkpoints.py` and `probe_counterfactuals.py` write JSON inside `evidence/`. Run them in a temporary checkout or restore the tracked files afterward if exact package hashes must be retained.

## Layout

- `dno.py`: main neural computation source.
- `train_synthetic.py`, `verify_checkpoints.py`, `probe_counterfactuals.py`: reproducible training and validation scripts.
- `evidence/`: **current reproduction** (new model weights, training metrics, fresh evaluation and counterfactual data).
- `verification/current_run/`: current test, training and verification logs.
- `tests/`: core and numeric interface contracts.
- `research_tests/`: optional independent observation/analysis tests.
- `examples/`: numerical interface examples.
- `archive/original_package/`: earlier sources, recorded outputs, math files and research archive files, unchanged.
- `verification/previous_audit/`: previous audit evidence (historical reference, not current reproduction).

External diagnostics such as `multiview_observer.py` are optional research utilities; they are not required parts of the DNO generation process.
