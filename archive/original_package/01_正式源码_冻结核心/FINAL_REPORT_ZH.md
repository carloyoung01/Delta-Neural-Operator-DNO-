# Delta 数学先行的 DNO 最终压缩实现：执行报告

**交付日期：2026-11-16。状态：本次封版。**

## 1. 为什么没有继续修改 v3/v4/v5 的事件清单

最早 `MATHEMATICS_ZH.md` 把 Delta 定义为**当前有效状态与条件性作用**，而非“若干固定事件类别的搜索算法”。后续代码为了将概念落地，不断外加候选表、调度器、接触门、结构增长类别和管理器；每一次工程化都带来新限制。用户提出的“可能性本来就在当前状态中，以压缩表示存在，再依据现实输入展开”，要求把模型重新收敛为有限的统一生成运算，而不是重新叠加更多有名事件。

本实现采用 **一个当前态 + 一个共享生成映射 + 按需作用 + 精确零支撑释放**。关系与组合是具有自己当前状态的普通承载体，通过实际关联参与以后的作用，不需要特殊记忆类型或固定搜索插件。

这是一项可复现实验性数学解释，**不代表其为 Delta 原理的唯一或最小可能实现**。

## 2. 最终代码做了什么，不做什么

| 范围 | 本次核心 | 验证依据 |
|---|---|---|
| 当前历史压缩 | 持久态只保留当前内容、边界、局部规律、支撑、局部时间、连接与观察取向；不存过去事件文本 | 代码结构、重复运行反事实 |
| 局部自身演化 | 同一共享 `generator` 的单端调用；无新输入继续递归 | 单元测试与64组间接对照 |
| 相互作用 | 同一 `generator` 的双端调用；同时改写两端，并可生成一个第三承载体 | 显式组合与30/64随机初始生成 |
| 关系成为单元 | 新组合也带稳定身份、边界、局部规律与支撑；它能再次组合 | 递归组合单测 |
| 可能性压缩 | `propose` 每次仅根据当前状态计算一次两端地址与活动支撑；没有关系对全集和事件名表 | 源码审计、条件干预 |
| 有效历史 | 接触后即使清除对应新关系，变化仍留在当前端点状态 | 64/64反事实 |
| 可观测与不观测 | `evolve` 不读取所有单元来偷偷更新观察；`attend` 才主动感知当前结构 | 隔离测试 |
| 当前局部规律 | `law` 是参与演化并被 `generator` 读取的有效条件 | 边界/规律干预单测 |
| 动态消散 | 非负 `support` 变成精确零后自动释放承载体与无效关联；无需计时淘汰 | 精确零释放单测 |
| 训练能力 | 共享寻址可通过最终数值差学习；共享演化可通过最终分类学习一位历史 | 两个种子各两项训练及控制 |
| 领域收缩条件 | 不强行规定物理、语言等领域都用同一种约束器；调用方可以选择实际输入/执行 | 基础核心不设领域事件表 |

**关键限定**：底层仍定义了“单元自身演化”“一次双端组合”的有限运算语义。这并非取消一切固定原语，而是用一种可递归复用的基本组合取代繁杂的具名事件类别。每次生成至多一个新承载体，完整无限分支不可能在有限机器上提前展开。

## 3. 实际测试结果（均本次重新运行）

### A. 数学原则的执行测试

`python -m pytest tests/test_final.py -q`

**32/32 通过**。包括：状态即下一次输入、无外部输入仍自主变化、边界和局部规律的真实因果效应、局部提示不全局广播、关系非必然消息发送、统一生成器的自我/两端调用、关系自身再次组合、零支撑停止与释放、稳定身份、没有强制接触、观察与非观察分离、梯度传播、条件输入与选择、时间与结构有效性。

### B. 64组未训练随机初始化的状态反事实

`python probe_counterfactuals.py`

- 随机初始化共 **64** 组；执行一次普通两端组合后 **30/64** 留下新的正支撑承载体，**34/64** 没有留下。
- 组合后的新关系如有产生，再将其释放，仅保留现在受影响的端点状态：与完全没有发生这次作用的当前态相比，**64/64** 的后续单元状态仍有非零差异。
- 形成关系的30组中，仅修改关系自身的当前内容，随后的**无接触局部流**对原端点影响精确为零：**30/30**。
- 同样30组中，关系状态改变之后的寻址概率出现差异：**30/30**。

这些是模型初始随机权重的结构行为观察，**没有训练生成什么类型的关系才有意义**。30/64不是有用关系发现准确率。

### C. 最终结果监督的双端识别训练

`python train_synthetic.py --pair-steps 450 --history-steps 350`

任务：4个当前单元各有符号键和随机数值，当前输入只给两个符号键，训练目标仅是两个目标数值之差。**没有提供源/目标索引作为损失标签**。两个独立初始化（13、29）都在独立测试中达到源、目标识别各 **100%**；最终数值结果 MSE 分别为 **0.0002743**、**0.0003004**。去掉查询条件后，MSE 分别上升至 **1.5158**、**1.5783**。

这是有限的符号键寻址与结果计算能力，不证明普通自然语言的语义抽象。

### D. 当前状态承载历史的训练

任务：输入一个0/1初始标记，再输入多个随机扰动，只在最后要求判断最初标记。**没有记忆锚点标签**；只使用普通最终答案的监督损失。

独立初始化17、31，分别在延迟3、7、15的独立测试达到 **100%**。清除最初标记后，准确率分别为 **50.39%**、**54.39%**，接近随机猜测。

这是**一位信息的受控短历史能力**，不能推出对开放世界的无限历史压缩。之前的 v0 已能在类似任务表现良好，所以也不应冒称为这次新核心才发明的能力。

### E. 训练权重的独立重载验证

`python verify_checkpoints.py`

4份权重以 `weights_only=True` 重新加载，独立重新采样：两个双端寻址模型各100%来源/目标识别，MSE分别约0.000289、0.000279；两个历史模型在延迟10的受控测试均100%，清除历史输入后分别约51.27%、51.86%。**4/4检查点通过。**

## 4. 本轮实际发现并修正的原则性反例

**反例：未请求观察时的全局信息泄漏。** 早期极简草案在每次 `evolve` 内自动求全体单元的均值来更新观察状态；即使没有执行真正的观测，不相关单元也可能经由观察状态影响未来寻址。这违反了原始数学中“观察/非观察可分离”的要求。

修复：自主 `evolve` 不再读取全体结构形成观察摘要；`attend` 是可选的显式读取，且复用原有观察更新权重。修改后32项相关单元/整体测试通过。**这是从数学反例导出的有限必要修正，并非增加一种事件类别。**

## 5. 真实尚未达到的部分（不偷偷改写目标）

1. **不可计算的任意可能性没有被有限代码穷尽**；潜在后继是按需展开的数学映像，不是万能发现引擎。
2. **严格动态可达性**没有证明；所有当前正支撑的可见承载体仍可得到正的 softmax 寻址概率，应用权限等必须由真实环境/运行规则执行。
3. **新关系是否有用、应否长期保留未由这些训练任务学会**。双端寻址的成功不能当作长期自主抽象组织生成的证据。
4. **关系/单元数量可以增长，也可能占用越来越多资源**；仅清除精确零支撑不保证最小描述长度或无限时间稳定。
5. **共享网络参数在推理时固定**；`law` 可内生演化不代表已经自主生成任意新执行原语。
6. **整数身份分配与浮点张量维度属于实现边界**。这并不等于数学上不存在未知或无限分支。
7. **未训练自然语言模型，也未测真实能耗或与 Transformer 的相同预算竞争力**。
8. **离散新结构产生的决策仍有不可微的零支撑分支**；本次训练主要验证结果监督下的寻址与简单状态历史，不证明完整长期结构决策可用单一梯度自动学会。
9. **“压缩到极致”是设计收敛，不是信息论最优压缩证明**。源代码还必须定义执行和存储操作。

## 6. 本次定稿判断

**经过检验，可以保留的最小命题**：当前态通过一个共享、可训练的局部生成规律自主变化；实际相互作用会重写当前态，可能形成可再次参与作用的新结构；历史不是日志，可能性不必是预制事件表，而是当前态与生成规律随条件展开的后继映像。观察和不观察可以区分；上层应用不需要被底层统一限定为语言或某一套关系搜索规则。

**不予宣称的命题**：代码等同于 Delta 的完整数学、已经获得通用抽象智能、无限可能性可计算、自动优于 LLM/Transformer、完全无需有限规则。

此版本按本次要求封存；不附加下一版计划，也不提出问题。
