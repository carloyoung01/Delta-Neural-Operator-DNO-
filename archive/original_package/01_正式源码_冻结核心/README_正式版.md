# Delta DNO — 正式封存研究代码（不再增加底层概念模块）

这是一次**发行整理**，**不是新增的 Delta 算法版本**。原已封版 `dno.py` 原样使用，SHA-256：

`fea8d9ea81c94dbf926b984b3c158f301afc71782f989c73b3c9bd02fac767b1`

原封版32项测试与4份合成训练权重、训练/反事实脚本、最早的数学材料均保留。新添加的是**叙述档案、出处、运行审计和可选输入示例**；这些文件不被 DNO 加载为训练或推理模块。

## 为什么保持原样

此前不断从素数、维度、有限未来签名、有效性判定、因果研究等视角推导。许多研究确认了可运行的有限机制，但也反复出现“解释概念→人为添加新模块→实验通过→再推一个版本”的循环。核心已有历史后果在当前状态、局部规律与边界反过来影响演化、关系作为承载体再次作用等基础。本正式版将解释移回文本，而不将每一个解释变为必须执行的规则。

## 目录

- `dno.py`：**唯一正式 DNO 动力学内核**，与冻结文件逐字节一致。
- `tests/test_final.py`：未修改的32项原核心测试。
- `train_synthetic.py`、`verify_checkpoints.py`、`evidence/*.pt`：原冻结合成训练及四份预训练检查点。
- `MATH_FINAL_ZH.md`、`FINAL_REPORT_ZH.md`、`FROZEN_SCOPE_ZH.md`：原始封版数学与报告。
- `reference/`：最早 v0 数学、代码及先前约定，保持原件。
- `docs/01_完整研究记录_问题尝试训练结论.md`：全部主要方向、失败、训练结果、为何不再合并。
- `docs/02_数学理解与代码对应.md`：不强制命名/规则的数学理解以及代码真实边界。
- `docs/03_图像视频声音_单元表示预测与检验.md`：跨模态定性预测、外部研究对照和明确的证据限制。
- `examples/units.py`、`examples/run_units.py`：外部输入的数据适配器与合成执行验证；**不是 DNO 的固有模块**。
- `tests/test_modal_interfaces.py`：外部示例的接口/隔离与文件保护检查，不是视觉/语音任务成绩。
- `release/`：重新执行的日志及包完整性清单。

## 运行

环境：Python 3.10+、PyTorch、pytest。需求列于已有 `requirements.txt`。

```bash
python -m pytest -q tests/test_final.py tests/test_modal_interfaces.py
python verify_checkpoints.py
python examples/run_units.py --out evidence/multimodal_demo.json
python demo.py
```

4份模型检查点来自极小的合成任务：需要寻址的一对数值差，以及跨干扰保持一位历史；它们不是LLM、多模态基础模型或商业模型权重。`examples/units.py`只负责把不同媒体的输入转换为 `[N,d]`，并未训练真实媒体任务，不能从运行成功推断识别准确率。

## 本次正式版的证据等级

- **原核心代码未变**：字节哈希与原冻结源文件对照。
- **原核心合同测试**：32项；前次已测试，本次再执行。
- **额外接口测试**：另16项；记录外部示例可执行，不增加底层能力。
- **检查点复验**：4份原封版权重在新采样的合成数据上重新评估。
- **未验证**：真实图片/视频/声音训练，跨模态强基线，同预算LLM比较，长期资源稳定性、任何企业等级质量/能耗指标。
