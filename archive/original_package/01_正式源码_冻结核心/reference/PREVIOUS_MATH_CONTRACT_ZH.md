# Delta 数学约束 → 可否被代码证伪

## 不是从已有 PyTorch 模块倒推出一个“Delta”定义

本研究沿用要检验的理论表达：

\[
\Omega_{t+\Delta t}\in\mathfrak D_{\mathcal B}(\Omega_t,E_t,\Delta t).
\]

这里的 \(\Omega_t\) 是当前有效单元、关系、边界、有效局部规律、观察状态与局部时间等，不是整个事件日志。\(\mathcal B\) 表示一个实际系统不可避免的有限执行基础。理论上“开放的未知”**并不等价于**有限程序能够枚举或生成所有可能性。

我们明确把原理拆成**可否证命题**，而不是要求每个符号必须存在同名变量：

1. **状态递归**：相同权重和当前状态以及当前输入，决定同一确定性连续流结果；没有历史日志也可以继续运算。测试 `evolve`、当前状态复制对照。已确认。
2. **当前边界及有效局部规律是因果条件**：保持其他条件不变，干预它们改变后继有效状态。32随机初始化确认。
3. **关系的存在不自动等于对外发送消息**：仅保留与删除未接触关系，两端单元的自主流相同；关系自身可改变。32组确认。
4. **已有关系应具有可检验的未来可能性作用**：干预关系内容应可能改变后续地址选择。最初失败，`_keys()` 改为依据当前相邻关系支撑量组成寻址键，32组确认。这是基于失败测试的必要修补。
5. **候选发现不能被一个固定的有名事件类别集合劫持**：核心不含 `EVENT_KINDS`、不调用 `_proposals`、不构造所有 `N(N−1)` 个有向单元对；使用两个学习到的地址分布，单次寻址按现存单元和现存关系计费，大约 `O(N+E)`。**但是全体单元键仍需被读取**，不等于严格物理局部性。
6. **输入可以是内生的**：把条件保存在 `observer` 当前向量而不是本轮 `external` 中，依然能训练选择正确的双端对象。已验证简单合成任务；这里的观察向量由上层适配器写入，尚非自主产生语义问题。
7. **历史表现为当前有效状态**：简单延迟信息任务，经过干扰后仅凭当前单元状态回答第一项输入，普通标签监督，没有历史锚点标签或事件日志。已验证1bit任务，不是无限压缩证明。
8. **观察模式应具有有效因果性**：当前观察向量改变寻址与读出。测试确认。但目前观察向量即使没有明确读出请求也会随全局摘要改变，**尚没有证明真正不观测的动力学**。
9. **可能性的变化**：当前状态改变地址分布，旧关系改变地址条件。已部分确认；对软最大值未加掩码的可见单元，候选概率始终大于零，因此严格的当前状态内生“不可达性”没有证明。
10. **生成机制可以自身改变**：有效局部规律向量在运算中改变，并影响后继运算。已确认；但共享 `nn.Module` 参数不会在推理中自动重写，内核也不能生成任意新原语。不能据此声称 Delta 完全实现。
11. **选择、转化、压缩、开放**：它们是数学上的功能性描述，不是四个必须固定排列的代码函数。新实现的状态更新/接触/精确零质量压缩分别提供有限对应物；不证明它们具有理论上的一般完备性。
12. **零关系不代表不存在计算限制**：常态存储容量有限；内生新单元目前并不生成，环境 `introduce()` 和 `retire()` 是显式边界。不能把训练不足冒充这项路径已实现。

## 独立形式的执行模型（**只是一个待检验实现假设**）

- 自主演化： \(\tilde\Omega=F_\theta(\Omega_t,E_t,\Delta t)\)，单元在没有联系消息时独立演化；关系及其有效规律独立演化。
- 寻址：\((q_s,q_t,\lambda)=A_\theta(\Omega_t,E_t)\)。已有关系的内容只通过当前端点的关系上下文影响这个查询。每次生成**一对源、目标分布**，没有固定的事件枚举表。
- 真实可执行作用：环境/可选运行时决定是否执行 `contact(Ω,source,target)`；通用 `W_θ` 对当前两个端点及可能存在的关系进行改写。新关系是否保留取决于可学习支撑量是否大于零；零是 ReLU 支撑定义，不是一个领域硬编码接触门槛。
- 选择时间：仅 `runtimes.py` 提供一个伯努利网格参考采样器，其他应用可替换。不称这种时间选择为 Delta 数学的必然律。
- 可微松弛：`soft_contact` 是训练工具，**不是离散接触非线性结果的精确期望**。

**数值重要性**：Euler积分拆分会出现差异；代码不保证严格连续时间半群、拓扑变更下任意不变量或无穷维记忆。

## 什么时候改代码，什么时候不改？

- **不需要改核心**：某个任务没有学会暂时不参与、保存简单过去内容、关联识别，先训练/控制实验。
- **需要修正确凿的执行缺口**：例如最初关系内容根本不进入寻址（已用反事实证明），或错误身份重用导致对错误对象接触（本研究使用稳定ID）。
- **仍未解决，不以编程替代证明**：严格的内生可达性、无预置发现策略的开放式复杂组织、任意自生单元、动态基础可执行原语、长期有用历史锚点、能耗优越性。
