# Delta → DNO：最终压缩的数学约定

> **本文件是对最早定义的极简可执行表达，不是对 Delta 普适性的数学证明。**
>
> 源头依据见 `reference/ORIGINAL_V0_MATHEMATICS_ZH.md`；它写明独立单元、有效当前状态、相互作用、关系自身成为结构、边界变化、观察/非观察、有限底层规律与开放结果、以及目标中立性。后续“存在、关系、结构、状态、历史、变化、观察、可能”八域及承载/关联/转换/开放四种抽象，在此不展开为八个管理器或四个固定执行阶段。

## 一、压缩为一态、一律、一次作用

唯一的持久计算状态：

\[
\boxed{\Omega_t=(\{(i,x_i,b_i,\ell_i,\mu_i,\tau_i)\}_{i\in I_t},\;L_t,\;o_t)}
\]

- \(x_i\)：当前有效内容；\(b_i\)：当前边界；\(\ell_i\)：可演化的局部有效规律；\(\mu_i\ge0\)：存在支撑；\(\tau_i\)：局部时间。
- \(L_t\)：当前连接/接合结构，只记有效的 **稳定身份**，并不是历史事件日志。
- \(o_t\)：当前观察取向，既可以作为本轮输入，也可以在不读取其他单元的情况下独立演化。
- **关系同样是有效承载体**。一次作用生成的第三承载体 \(c\) 通过当前关联 \(a\to c\to b\) 加入结构，之后完全可以像普通单元一样变化、相互作用或再组合。不建立单独的“关系种类”管理器。

有限共享执行规律：

\[
\boxed{(\delta a,\delta b,c)=G_{\theta}(a,b;o,e,\Delta t)}
\]

这是一个**可训练的统一生成映射**。本轮只提供一个对象时，第二对象为空，执行自主变化；提供两个实际对象时，可以修改二者，并可能留下一个具有正支撑的新结构。这里的空输入、双端作用和支撑为零的结果是有限代码的执行语义，不是从宇宙数学定理推出的。

历史、压缩和下一态不是三个档案：

\[
\boxed{\Omega_{t+\Delta t}=\operatorname{Canon}\bigl(\operatorname{Apply}_{G_\theta}(\Omega_t,e_t,a_t,\Delta t)\bigr)}
\]

`Canon` 仅释放**精确零支撑**的承载体及无效关联；并没有一个固定的年龄截止、重要性标签、记忆锚点或与领域有关的阈值。其他过去影响只要继续存在于当前 \(x,b,\ell,L,o\)，就已经成为下一次作用的条件。\(a_t\) 可以不发生；没有必须执行的固定事件时钟。

## 二、可能性不是枚举的列表，而是压缩后的可展开映像

\[
\boxed{\mathcal P_t\;\equiv\;\operatorname{Im}\!\left[\;(e,a)\mapsto
\operatorname{Canon}\bigl(\operatorname{Apply}_{G_\theta}(\Omega_t,e,a)\bigr)\;\right]}
\]

此定义是**数学上的潜在后继映像**。计算机不会提前把 \(\mathcal P_t\) 展开、缓存或遍历。`propose()` 只在实际需要时，根据**当前状态和当前观察条件**生成一次来源、目标的概率以及是否发生作用的支撑。新的输入、边界、局部规律、观察取向或新组合产生后，这个映像自然改变。

因此：“**可能性存在，但被压缩在当前有效状态和有限共享规律中，按需展开**”是本实现采用的可检验解释。它**不意味着**有限张量已经储存了所有数学可能性，也不意味着没有来源的信息会凭空得到发现。

## 三、最初抽象如何不再额外写成代码

| 原始抽象 | 极简代码中的实际载体 |
|---|---|
| 存在 / 独立 / 单元 | `State` 内的任意有效承载体；各自局部流 |
| 共存 / 关联 / 关系成为实体 | `links` 及生成后可再次参与作用的承载体 |
| 结构 / 边界 / 规则 | 当前 `boundary`、`law`、关联结构；共享生成映射读取并更新这些条件 |
| 状态即历史的有效结果 | `State` 只保存当前张量，没有过去事件列表 |
| 执行 / 转换 / 递归 | 同一 `generator` 处理自主变化与双端实际作用 |
| 遗忘 / 释放 / 压缩 | 精确零支撑经 `compact` 释放；不进行强制过期 |
| 观察 / 非观察 | 自主演化 `evolve` 与显式 `attend`/`observe` 分离 |
| 分支 / 未知 / 可能 | `propose` + 当前状态的多种反事实作用，不保存预制候选全集 |
| 规则自演化 | `law` 随作用变化，继而改变后续作用；**不等于**自动改写 `nn.Module` 参数或生成新机器指令 |
| 最小变化 | 共享残差变化与条件支撑提供一种实现形式，**不是**全局最小化定理 |
| SPO 自耦合 | 当前结构与观察状态共同影响 `propose`/`compose`，后继结构反过来改变可能作用；未假设三者分别拥有独立的万能生成器 |
| Φ / Δ / C 等形而上解释 | 可用于研究动机；不强制在无目标的 DNO 底层植入偏好函数、差距最大化或不可逆承诺指令 |

## 四、不可删除的真实计算边界

1. **存在有限原语**：固定维度、共享神经网络、张量算术、一次/两端组合、数值时间步长。移除事件名和候选表不是取消一切程序语义。
2. **可能性没有严格完备性**：`propose()` 读取当前所有有效承载体，单次约 \(O(N+|L|)\)；不保证复杂结构的所有潜在关系能被及时发现，亦不保证整体长时运行线性。
3. **学习的边界并非严格物理禁令**：softmax 对所有可见且正支撑承载体仍分配正概率。严格权限、真实空间碰撞等可以由领域运行环境施加，不应偷渡为所有 DNO 都必须执行的统一限制。
4. **自主生成仍有限**：每次实际双端组合作用至多产生一个新的当前承载体；多轮作用能形成更多层级，但这不是数学上的无限分支或任意新原语生成。
5. **压缩是有效状态表达，不保证最小信息量**：`compact` 仅清除精确零支撑；没有证明状态是任务充分统计量，更没有证明它无损保存全部历史或最优节能。
6. **训练不是自然律**：合成训练任务的监督信号来自外部，只用于检验表达能力；不能从有限测试推导开放语言理解、普遍智能、意识或物理定律。

**因此，最终代码完成的是最初 Delta 原则的一种尽量小、可运行、可否证的 DNO 骨干，不是声称数学思想已经由代码穷尽。**
