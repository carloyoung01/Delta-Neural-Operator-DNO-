# 多坐标、多尺度观察：独立于 DNO 生成核心的研究方法

## 1. 这次解决的是哪一种误判

过去常在一个固定观察点上遇到“尚不能解释”，然后推断 DNO 缺少对应组件。用户最终指出：同一生成过程在局部、整体、时间、关系、空间、功能等尺度下可能表现不同；一个现象在某个坐标里看不见，可能只是该观察没有覆盖它。

因此数学上必须把两件事分开：**生成过程** `U_{t+Δ}=T_θ(U_t,e,Δ)` 与**对生成过程的观察** `y_i=V_i(U_t)`。固定生成器 `T_θ`，允许研究者选择若干 `V_i`，既不向系统注入解释规则，也不因 `V_i` 不充分就修改 `T_θ`。

`U_{n+1} = U_n >> (U_n ⊕ F(x) + ∞-branch + ▽min)` 是对整个持续生成的一种抽象视角；其符号未给出唯一运算公理，因此不拆成必须顺序执行的算法管线。

## 2. 换视角的严格含义

给定两种当前状态 `a,b`，单一观察可能满足 `V_1(a)=V_1(b)`，另一观察却满足 `V_2(a)≠V_2(b)`。前者只是**未区分**，不是两状态全局相同的证明。若测试无区别或观察不可用，只能返回**当前无法判断**。

外部观察类别只起研究导航作用，并非 DNO 内核的本体定义：

- 全局汇总与身份对齐的局部内容；
- `value` 与 `law/boundary/support/age` 等当前有效字段；
- 当前连接 `links` 与 `propose()` 主动寻址概率；
- 当前观察状态 `observer` 与按需显式 `attend()`；
- 当前切片、有限假设性 `evolve()` 时间滚动及时间步长的离散化比较；
- 纯坐标转换、投影后的丢失信息和不同观察精度。

数学限制：可逆变换不产生新信息；投影会丢失区分；时间滚动由冻结模型生成，是内部预测，**不等于外部现实证据**；稳定 `ids` 是工程标识，不能自动等同真实世界语义身份。

## 3. 观察判断允许三个结果

1. **有差异**：指定观察下的测量跨过有根据的数值容差。
2. **未区分/证据不足**：所有指定观察没有发现差异；无法推出全局等价。
3. **观察不可用**：缺少模型、时间/字段不合法等；不把失败当成等价或模型错误。

原观察器 `compare()` 的上层结论只有 `difference_found` / `undetermined`，逐视角的 `ViewEvidence.finding` 还包括 `unavailable`。所以“未判断”包含“测不到”和“测到了但不能区分”，必须查看 `trace` 才知道是哪一种。**这套输出是外部测量而不是核心自动思维能力。**

## 4. 为什么保留原观察器的一个已知缺口

原 `multiview_observer.view('full')` 拼接了数值、边界、规律、支撑、时间、observer 和连接等有限量，却没有包含身份标签。160个仅变换身份标签的受控案例全部漏检。这叫**观察器有效覆盖范围不足**，不是冻结 DNO 的缺陷。因此我们没有篡改旧 `full` 的行为以抹掉历史反例，只用独立的 `extended_readonly_views.identity_distinguished()` 作为额外观察。

特别注意：大量视角一致也不构成“全部可能视角一致”。今后若某项真实任务持续失败，仍应先检查数据与视角，再判断是否有核心可复现缺陷，而不是永久禁止研究模型本身。

## 5. 与用户提出的“坐标压缩”对应

程序用单个数值向量存储复杂状态是一种有限表示选择；这不意味着所有可观察结构都必然压缩成一个数学坐标，或靠多画几个维度就能恢复已丢失的信息。真正有用的是：**从同一个结构中取出不同可检测的局部切面，在一定条件下比较它们是否兼容**。视角顺序随研究任务而变化，不应写成 DNO 的强制生成顺序。

已有数学工具包括坐标共轭、延迟嵌入、Koopman 可观测量、局部—整体一致性分析与流形学习；它们是可选择的研究手段，不是代码已获得那些方法完整理论保证的声明。

## 6. 操作边界

这里只修改观察分析脚本、文档与复现实验环境；`dno.py`、训练检查点、已有状态数据结构和原数学封版约定保持原样。任何额外解释不写进推理时的主模型。
