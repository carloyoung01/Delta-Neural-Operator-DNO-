# Delta DNO 正式研究记录：从生成性抽象回到不强制定义的最小核心

**记录日期：2026-11-16。记录性质：对已有研究与真实执行结果的审查；非新的理论公理、非新的架构迭代。**

本文件保存这段研究的**思路、反例、尝试、训练结果、失败、最终取舍及其原因**。每项结论标明它属于数学假设、代码测试、合成任务训练还是未验证预测。历史实验的数值来自已有研究文件；未经本次重跑的历史结果明确标记为“归档记录”。本包原始生成核心是冻结的 `dno.py`，不是最后的 `effective_recursion.py`、素数频率或 SVD 实验。

## 0. 最终确认：我们要停止误把解释变成新的计算限制

Delta 原始关切不是“用语言写出全部状态种类，然后由状态种类决定什么可以发生”。它关切：当前有效状态、关系与局部结构能够持续产生变化；变化后的当前结构本身承载过往作用的结果，并影响下一次发生什么。我们叫它关系、规律、边界、记忆、视角、身份，这些都是**对同一运行过程从不同尺度作出的描述**，不应自动转换成六种强制执行的模块。

最初不断添加新版本，常因为某个抽象尚未在代码中被显式命名，就推测它根本不存在；再增加一个同名模块、一个判定阶段或一个阈值。多数“通过”只说明新模块满足我们刚写的测试，并不说明原核心缺少那项能力。用户在后续讨论中明确指出：程序的作用与生成过程本身就是当前计算的因果依赖；不必为了说明每个变化，再给它增加额外的因果解释器。**语言描述能辅助审视，不能决定数学结构只允许语言描述过的变化。**

因此本正式交付采用：保留有限计算原语、原样冻结已经实测的共享生成核心；把历次研究作为**独立外部验证资料**，不把它们全部合并到底层。

## 1. 概念源流：哪些思想是前提，不是后来新造的模块

早期 Delta 论述提出独立、共存、连续/离散、边界、层级、规则、历史、记忆、未知；后续讨论把这些视为可随观察视角改变的结构。行动/状态/环境构成循环，且一个作用可以改变之后的作用条件；历史的有效后果体现在当前结构，不需要保存完整事件日志。

曾使用八个观察域：存在、关系、结构、状态、历史、变化、观察、可能；再概括为承载、关联、转换、开放。它们的价值是**说明同一结构的几个侧面**，不是要求代码必须有八个管理器或四级调度流水线。参见归档的 `reference/ORIGINAL_V0_MATHEMATICS_ZH.md`、`reference/PREVIOUS_MATH_CONTRACT_ZH.md`。

另一个核心公式

\[
U_{n+1}=U_n\gg(U_n\oplus F(x)+\infty\text{-branch}+\bigtriangledown_{\min})
\]

可以帮助理解“当前整体—作用—未预先列尽的可能性—保留有效变化—新的当前整体”。其 `>>`、`⊕`、`∞-branch`、`▽min` **尚无满足一般数学唯一性的严格运算定义**；它既不是现有代码里的四个固定步骤，也不证明某个普适的最小化目标。禁止把它机械翻译为四个必经类/模块。另见 `docs/02_数学理解与代码对应.md`。

## 2. 按研究阶段复核，哪次发生了什么

### A. 最早 v0：有限槽位的递归关系原型

归档：`DNO_research_v0/TEST_REPORT_ZH.md` 和本包 `reference/ORIGINAL_V0_CODE.py`。

实现特点：当前状态在后续步骤被继续使用；单元、边界、关系可被改变；关系影响后续计算；历史不是额外原始输入的重放。最早的固定槽位、固定接触候选、语言词表头是**工程限定**，不是 Delta 数学必然要求。

实际归档训练：合成“重复三个符号”的序列（长度12，词表13），300个 AdamW 更新，验证 next-token 交叉熵从 **2.7274 降至 0.6632**，验证准确率从 **6.66% 升至 84.90%**。同一轮消融发现：关闭关系再次作用后准确率 **85.01%**，反而略高于完整版本 **84.90%**；固定接触损失 **0.5609** 好于动态接触损失 **0.6632**，但准确率另有差异。**结论：可以学会一个合成规律，但不能说动态关系在该任务上已带来净增益。**

后来的审计在**不修改 v0**情况下又训练了一个延迟一位信息任务：3个种子，先输入0/1、经过干扰、再回忆，干扰长度3和7的独立测试均达100%；清除开头信息则约45.7%–49.4%。这直接反驳“没有专门历史锚点模块，就不可能保留历史”。但是只是一位二分类记忆，不证明复杂或无限历史学习。

### B. 自适应研究 v1：增加增长、事件语法和运算图

归档：`DNO_adaptive_research_v1/TEST_REPORT_ZH.md`。

可以形成动态单元、关系、可组合运算节点；有限数值稳定性/结构干预测试完成；但训练发现结构增长多数由工程阈值与预算安排决定，没有可靠学会“何时有意义地增长”。合成模板英语关系问答在2500个更新后，DNO 的保留组合问答准确率 **0%**，小型 Transformer 对照 **100%**（参数量和 FLOPs 不等，单任务单种子）；DNO 的下一 token loss **1.05881**，Transformer **0.61438**。**负面结果必须保留**：不能以测试通过冒充已经拥有语言理解，也不能据此推论 DNO 永远不行。

### C. v2、v3：把“关系存在”与“关系实际发生接触”分开

归档：`Delta_DNO_composition_alignment_v2/CHANGELOG_ZH.md`、`Delta_DNO_conditional_participation_v3/TEST_REPORT_ZH.md`。

v2 一度为解释组合而新增事件名 `unit_assemble` 等；这是某个操作定义，不能成为一切组合的必选事件种类。v3 对20个初始化比较：关系**仅仅存在**时，v2 的单元连续变化20/20受到影响，v3 的20/20均精确隔离；另32个随机初始状态在60步无接触期间，关系仍自身变化而不被强制传给单元。一次明确真实接触后32/32产生后续影响。

在v3的受控发生率训练里，3种子共360次采样：端点线索下出现307次目标接触，无关单元线索下22次；继续自身演化后端点245次、无关8次。**这是人工监督“哪里放线索”的学习，不是自主发现普适的接触意义。**

### D. v4/v5：从所有两两候选退回实际暴露和现有结构

归档：`DNO_v4_exposure_probe/README_ZH.md`、`DNO_v5_multi_hypothesis_probe/REPORT_ZH.md`。

v4 删除所有单元两两自动枚举候选的假设，用当前关系和本次真实暴露提供候选；这减少不必要的二次规模表，但可能依赖外部暴露。v4 有**旧位置索引在增删单元后指错身份**的接口风险，说明新增事件管理逻辑会制造具体缺陷。v5 的两跳/共同线索发现仅是**可选应用策略**，不能声称它自动学到自主关系发现。稀疏链 N=160 时手写策略提出158个新候选，与所有有向对25440个形成对照；不代表所有结构都线性规模。

### E. 数学先行的压缩封版：把存在的能力还给同一个共享运算

直接采用本包根目录 `dno.py` 和 `MATH_FINAL_ZH.md`。源文件SHA-256 = `fea8d9ea81c94dbf926b984b3c158f301afc71782f989c73b3c9bd02fac767b1`。

核心是：当前 `State` + 同一共享 `generator` + 自主演化 `evolve` + 实际相互作用 `compose` + 当前机会 `propose` + 非必选观察 `attend/observe` + 精确零支撑的释放 `compact`。没有强制事件表、全对候选枚举、独立记忆档案、固定历史锚点和必须执行的全局事件时钟。`law`、`boundary` 等名字表示**有效张量角色**，不是它们只能对应语言上的某种实体。

归档32项测试通过；64个随机初始种子中30次真实产生新承载体，64/64反事实保留了接触对后续状态的影响。两个合成训练：

- **当前寻址**：种子13/29，450次更新，保留测试MSE分别 **0.0002743 / 0.0003004**，来源和目标定位各100%；移去问句则MSE升到1.5158/1.5783。
- **一位历史**：种子17/31，350次更新，干扰长度3/7/15的独立测试准确率均100%；抹掉最初输入则约50.39%/54.39%。

本正式包包含4份训练检查点，且本次重新加载全部4份，用新随机测试重新验证，具体数值见本包 `evidence/checkpoint_verification.json`。**这些是有监督的极小合成任务；不说明自然语言、开放生成、视频理解、声音识别或低能耗已实现。**

### F. 为什么后来研究了维度、素数、可区分性、有效区间

原始问题是“同一个系统在某种观察下看不见关系，能不能从另一维度/尺度看见”。借黎曼猜想的表象提出的是**改换数学推导视角**，并非“素数决定 Delta 规律”。曾将素数的对数频率当作一种多尺度坐标，比较素数/整数/随机频率：素数构成的目标，素数频率外推MSE **0.00239** 较优；中性目标整数频率MSE **0.00434** 优于素数的 **0.06021**。**没有证据支持把素数频率写入核心。** 归档 `Delta_DNO_prime_multiscale/REPORT_ZH.md`。

动态维度实验 `z=x_1x_2`：显式增加第三有效坐标好于二维线性基线，但固定非线性网络同样能极低误差；**新维度是可行表示，不是必要架构修改证据。** 归档 `Delta_DNO_dimension_feasibility/REPORT_ZH.md`。

可区分性实验定义了**相对于指定有限干预和观察的未来响应签名**。首次只用固定作用训练，未见组合条件最大误差达 **0.5404**；改为连续作用训练后，三个初始化最大误差 **0.03694 / 0.04126 / 0.02362**。问题不在于是否添加所谓“区分器”，而在于验证条件。归档 `Delta_DNO_distinguishability/REPORT_ZH.md`。

### G. 有效规律审查：已能隐式学习，并未证明必须增加发现器

归档 `Delta_DNO_effective_law_audit/REPORT_ZH.md`。冻结的 DNO 生成器和普通 MLP 对照，从同一组数值干预样本拟合一个条件性合成规律，后者真实边界并未作为训练标签。三种种子平均同域输出MSE：DNO **0.0000720**，MLP **0.0000516**；有限反事实作用边界位置误差：DNO **0.00819**，MLP **0.01036**。将 DNO 已有 `law/boundary` 通路置零，输出误差升至 **0.0013225 / 0.0013755**。**证实已有状态通路有效；没有证明新增“规律判定器”必要，也没有证明比普通MLP普遍更强。**

### H. 原公式的递归实验：有效研究工具不等于底层公理

归档 `Delta_DNO_recursive_law_probe/REPORT_ZH.md` 和 `Delta_DNO_recursive_final_2026_11_16/REPORT_ZH.md`。使用不同干预/视角、有限 SVD 响应、验证集与复杂度受限的状态修正，让发现影响下一次观察和 `evolve/propose/compose`。独立层使受控辨识任务测试误差从平均 **0.0034725** 降至 **0.000003355**，并能拒绝无变化及互相矛盾的观测。原封版32项加研究20项，共52项回归通过；该实验使用**同一共享生成器、隐藏一部分当前局部状态的模拟环境**，不是任意自然规律自主发现。

这些结果解释了**这种外部辨识流程能够用**，没有证明 Delta 必须分成“探索—判定—压缩—写回”四阶段，也没有证明核心模型必须携带独立 SVD 和新损失函数。

## 3. 实验反复通过，为何依旧感觉偏离？

核心原因不是“不可能通过”，而是**每个新实验为自己的定义提供了通过条件**。如果一次实验人为指定候选集、观察视角和判断什么算有效，实验通过不意味着系统已自主选择这些条件。另一方面，原模型的 `law`、`boundary`、当前状态和共享生成器已经能够表达某些随作用变化的规律；若只因为没有新模块名就视为缺失，会导致无穷次“补齐”。

我们的判断经历了两次纠正：

1. **不能因某个概念没有同名模块就判断能力不存在。** v0 一位延迟信息实验、封版历史保留与条件规律实测都反驳了这个推断。
2. **也不能因有当前状态和生成器，就宣称开放式所有规律已经实现。** 模型固定有限张量、共享网络参数、现有输入接口，且只有有限监督、有限数据、有限时间下的证据。

最终决定：保留已有最少工作机制，不再把外部数学解释的特殊坐标/阈值/验证阶段塞入内核；只有明确可复现的实际缺陷，且现有能力与训练不能解决时，才谈修复。这里不指定下一版。

## 4. 必须记录的限制，避免正式版包装成成熟大模型

- `d` 固定且有限，Tensor和神经算子仍是既定执行原语，不能凭空生成新的机器指令或无穷分支。
- `compact()` 仅清除精确零支撑，不证明最优压缩、最小充分表示或信息无损恢复。
- `propose()` 是一次需要时的概率寻址；**不是**无遗漏的关系发现算法，也不是自动执行事件的时间调度器。
- `compose()` 的第三承载体受非负支撑控制，每次实际双端作用至多产生一个；新承载体不保证具有任何领域语义。
- 网络参数在普通推理阶段不自行更新；随作用变化的是当前 `law`、`boundary` 和其他状态，不能声称重写了数学原语。
- 没有图像、语音、视频的现实任务训练；本正式版新加入的例子只是外部单位数据输入和运行合同测试。
- 没有同预算和同硬件的语言大模型、ViT、语音网络或视频网络对照；没有能耗、FLOPs、吞吐量、大规模容错与企业生产服务测试。
- 原版可能受固定宽度、局部表示、流式压缩的长期记忆瓶颈影响；不要把“保留当前后果”变成“可以无损存储任意过去”。
