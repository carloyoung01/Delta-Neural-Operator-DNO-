# 跨模态预测：DNO 的承载体在图像、视频、声音中可能如何表现

**预测性质：机制契合度假说，不是已经测得的图像/视频/语音能力。**

用户提出：DNO 不应仅被理解为语言模型的替代算法，它的抽象“当前有效单元—交错作用—关系与结构继续演化”可能在图像、视频和声音数据中有更自然的表现。这个判断**值得作为预测保存**，但必须明确分离三层证据：①代码能接收这些单元；②相关机制在任务上经过训练；③同算力的基线比较证实优越。现在只有①的外部数据接口实测，以及此前的若干合成任务②的局部证据；没有真实多模态的②、③。

## 1. 为什么这种预测有数学动机

语言模型常把输入分割为符号序列；符号的次序携带重要约束，关系还有句法、知识、长距离依赖等。图像直接包含空间邻域、形状边界、局部区域；声音包含时间连续、节律、频谱与重复；视频同时包含位置、运动、遮挡、时间与多个对象的关系。它们不必先被语言词命名，局部差异本身就可以构成连续信号中的当前单元。

DNO 的有限计算结构中：承载体可以来自连续输入；局部 `value/boundary/law` 与 `support` 可随作用变化；组合产生的新承载体可以再次作用；`attend/observe` 非强制；只需当前有效状态继续迭代。这些性质与时空数据有天然的**概念亲和性**。但 DNO 当前并没有自动理解像素邻域、物理位移或声学因果；只有外部表示适配器时，才会收到这些信号。

## 2. 图像：区域和对象之间的连续结构——**可能有帮助，但不一定最有利**

**假设输入单元**：像素块、局部特征区域、由任务编码器形成的对象向量。`image_units` 例子将灰度或 RGB 图像分割为二维不重叠 patch，再压缩成 `[N,d]` 纯数字向量。这里 patch 选择是例子，不是 DNO 的必选单元类型，更不是模型自动发现对象。现实图片需要处理不规则形状、尺度差异、遮挡和物体重叠。

**预期有利场景**：局部区域的状态连续调整、在相互作用中形成新的整体表示、可变对象数及关系、稀疏接触而不是所有块两两强制作用。**不利场景**：单张静态图像的全局空间理解、精准边缘和纹理重建、位置不变性；现有 `State` 没有显式二维坐标、卷积或已验证的跨区域构图机制。高分辨率图像的 patch 数仍大，若大量 `compose` 产生额外承载体，显存和时间不保证低。

**预测等级**：有研究动机；对于静态图像分类或生成，**没有根据宣布比 ViT、CNN 或扩散模型更强**。

## 3. 视频：相互作用随时间形成新结构——**当前最值得观察的契合点之一**

**假设输入单元**：时空块（tubelet）、运动轨迹、目标候选、运动边界、遮挡区域。`video_units` 例子把 `[T,H,W,(C)]` 分割成有限帧组与局部空间块；输入依旧是 `[N,d]`，**没有**把位置、帧号或物理运动定律塞进核心。真实任务的对象跨帧关联，需要额外编码和训练才能建立。

视频的难点通常不是“每帧是什么”，而是“同一事物怎样变化、两个事物怎样交错、某次接触怎样改变之后可能发生的动作”。这些与 Delta 的当前结构和持续相互作用叙述对应紧密。当前状态也提供一种不用无限回放帧列表的计算可能性。

**最强的可检验预测**：当任务主要依赖稀疏的事件交互、时空持续状态和变动对象数量，DNO 类当前结构机制经过足量训练后，**可能**相对简单的全帧扁平化序列处理具有更紧凑的状态表示；但面对长距离细节检索、复杂全局交互、细粒度动作识别时，固定宽度、遗忘及寻址错误仍可能伤害性能。时间步改变数值也不是严格时间连续动力系统的证明。

**预测等级**：对连续交互机制的假设强于静态图像，但模型性能并未验证。不能说已胜过 VideoMAE、VideoMamba 或视频 Transformer。

## 4. 声音：波形的局部演化与多尺度时间模式——**同样有潜在契合**

**假设输入单元**：短时波形、频谱帧、声源片段、重复节律片段。`audio_units` 将单通道短时窗转换成 `log(1+|FFT|)`、再压缩到 `[N,d]`。这只是普通外部预处理，并不等于学会听觉单元、声源分离、音素识别或生成音频。

**预期有利场景**：声学模式连续变化、多个声源相互影响、通过当前状态积累过去声学条件、分段环境噪声与时间间隔。**不利场景**：高质量语音重建需要保留相位和高频细节；例子只保留频谱幅度，还丢弃窗间部分关系；精确声学任务可能更适合卷积、专用频域编码或双向上下文。固定维度下不可恢复被抛弃的波形信息。

**预测等级**：在连续时间感知方面有研究动机；在语音识别和生成质量上没有基准证据证明优于 Conformer/Transformer。

## 5. 与 LLM 的关系不能做错比较

“图像视频声音单元表现可能更自然”不等于“DNO 在这些领域必定超越 LLM”。LLM通常评估文本生成，Vision Transformer/视频 Transformer/声学 Transformer是对应的强基线。**不同数据、任务和指标间没有可比的直接胜负**。

更准确的假说：

> 对于变化中的连续信号和相互作用结构，DNO 的当前承载体与状态递归可能提供一种比“先全部转成文本 Token 再解释”更直接的表示方式；若与专门的空间/时间编码和合适训练结合，在某些动态任务上可能具有效率或泛化优势。

但带注意力的多模态网络也直接处理像素块、视频块、频谱帧，并非都先转成文本。因此任何比较都必须针对**最强相关基线**，而不是“语言Token化”这一稻草人。

## 6. 本包已做的实际实验与证据界限

同一份**未训练** `DNO(d=8,hidden=24)` 权重，连续执行四组人造数据：

| 模态例子 | 数字化单元 | 运行检查 | 可以证明什么 |
|---|---|---|---|
| 8×8灰度图像 | 4个 patch 单元 | introduce→evolve→attend→propose→observe，有限数值 | 数字图像单元可输入相同核心 |
| 4帧8×8视频 | 8个时空块 | 相同 | 时空块可输入同一核心，不是动作识别 |
| 256点合成声音 | 4个频谱帧 | 相同 | 频谱帧可输入同一核心，不是语音识别 |
| 4个抽象符号向量 | 4个符号单元 | 相同 | 核心不强制某种领域词表 |

这些项目共有一个固定的8维外部数据合同，并没有跨模态可迁移训练。`tests/test_modal_interfaces.py` 还检查无强制接触、局部输入隔离、无隐式全局观察及非法形状拒绝。最终原始数字见 `evidence/multimodal_demo.json`。

**若这些测试全部通过，唯一可宣称的结果是“跨模态数值接口可执行、原核心逻辑与输入领域无直接绑定”**。没有评价 PSNR、SSIM、视频动作准确率、WER、PESQ、FAD、延迟或能耗，也没有图像、视频、声音的真实任务训练。

## 7. 将来如何真正验证预测（评价方案，不修改核心）

同等参数量、优化预算、数据与硬件对齐；预先固定验证集、跨环境保留集及回归基线。分别在图像分类/分割（准确率、IoU）、视频动作/轨迹预测（准确率、预测误差、长时漂移）、声音识别/分离（WER、SI-SDR等）评估。除质量指标，还要实测峰值显存、每秒有效输入量、训练能耗和推理延迟。需要消融“关系承载体再次作用、主动观察、当前局部规律、动态组合”，再看收益是否超出仅使用普通状态网络。必须报告失败、种子差异和规模曲线。

特别应比较：固定相同外部编码器 + DNO与同宽度普通RNN/GRU/SSM/Transformer；并限制它们享有相同空间/时间位置信息。否则提升可能来自输入编码或额外数据，而不是 Delta 原理。

## 8. 旁证研究（不是 DNO 的证据）

- *Mamba2D: A Natively Multi-Dimensional State-Space Model for Vision Tasks*（2024），https://arxiv.org/abs/2412.16146 ：说明空间维度的计算组织会影响视觉状态空间模型的表现；它不是DNO。
- *LocalMamba*（2024），https://arxiv.org/abs/2403.09338 ：强调视觉空间局部性和扫描方向的重要性，不能由此断言DNO自动具备空间归纳偏置。
- *Audio Mamba*（2024），https://arxiv.org/abs/2406.02178 ：不同模型家族在音频任务中展现状态空间方法的潜力，不是DNO音频成绩。
- *Video Mamba Suite*（2025/2026），https://doi.org/10.1007/s11263-025-02597-y ：视频中时空建模和时间结构很重要，但它的方法、参数和数据与DNO均不同。

## 9. 最终预测记录

**最有动机的预测：视频中“持续发生的多对象关系”，其次是声音中的“连续条件与多尺度时间”。** 静态图像也有潜力，但更依赖有效的外部空间表示；语言并非不适合，早期合成序列已表现出可以学习。这里只是对机制与数据结构的**定性排序，不是测试精度排序**。优越性的严格结论：**未知**。把“可能更自然”保留下来，而不把它固化成原核心的又一种限制，是这次封存的要求。
