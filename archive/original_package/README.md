## 研究主张

DNO 是一套以**当前有效状态、局部作用、关系递归和结构可演化**为中心的可运行神经计算研究架构。它面向可训练的底层生成过程，而非仅供调用的商业聊天模型。它的潜在价值应通过多种训练任务、比较基线及随算力变化的行为进行考察，而不从有限测试以外断言能力存在或不存在。

**已执行的正式测试：162/162 通过；四份合成训练检查点重新载入且复验通过；160种随机初始化的多视角压力测试已重新执行。** 这些数字是明确测试集合的验收结果，非“所有可能任务都已测试”。
