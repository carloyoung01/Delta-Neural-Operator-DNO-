# 正式发表时的证据表述规则

本文件用于修正先前偏重“尚不能做什么”的叙述，重点改为已有技术价值与可检验潜力，同时避免将尚未训练/尚未比较的行为声称为已证事实。

## 表述等级

**A 级：本次重新执行的测试。** 162项测试通过；四个合成训练权重载入并完成独立复测；160随机种子压力数据；冻结核心SHA256核对。可以直接写“通过”“检出”“在规定实验条件下达到”。

**B 级：历史保存的可追溯研究结果。** v0/v4回归、不同动态规律/素数尺度/增维/条件关系实验、训练日志和反事实记录。可写“历史研究记录”“在相应条件下观察到”，引用原报告与数据，并区分是否独立重测。

**C 级：由现有机制导出的下一步可检验预测。** 更大规模训练、时变结构、连续感知、跨模型训练及资源效率。写“预计值得探索”“可能出现”“可检验预测”，**不能提前改写成已取得的成绩**。

**D 级：未知与未定。** 未覆盖的数学可能性、新输入分布、未知观察尺度与大规模行为。写“当前观察未覆盖；未来通过训练与比较确定”；不得把“没有测试”写成“模型缺少能力”，也不得反过来写成“已经具备全部能力”。

## 建议替代用语

| 不推荐的绝对表述 | 建议的准确、正向表述 |
|---|---|
| “DNO 没有发现新东西的能力” | “现有实验已展示结构变化、关系再参与和条件影响；开放任务上的新结构发现潜力，需要更长时训练验证” |
| “DNO 不会理解图像或语言” | “同一核心已验证处理多领域数值单元的计算接口；真实模态任务的学习效果将作为下一阶段研究目标” |
| “它不能超越 LLM” | “DNO 与 LLM/SSM/Transformer 的训练目标与计算形式具有可研究差异，正式性能对比应以等预算实测结果为准” |
| “所有技术能力已被完全证明” | “目前纳入验收的技术措施在162项测试中全部通过，为更大规模训练提供可运行的研究基础” |
| “大算力一定会有意外突破” | “随着算力、环境与观察尺度扩展，有可能出现小规模任务未覆盖的差异化行为，应予记录和重复验证” |
| “同一观察指标没有发现差异，说明原模型需补一个模块” | “先更换局部、整体、时间、身份和关系观察视角；多视角仍无足够证据时，允许暂不解释” |

## 一个不应被隐去的反例

160次“仅身份变化”在旧`full`观察视角下被漏检；这属于**观察仪器的覆盖差异被实验证明**。对外可积极表述为“扩充观察坐标后，可以解释旧综合数值视角的盲区”，但不应在结果表中删除这160次漏检或把它记作准确率100%。科学可信度来自完整证据，而不是删除不符合宣传预期的记录。

## 本版承诺

1. 不修改 DNO 已封存的生成逻辑。
2. 不用外部观察视角替换核心数学原则。
3. 重点叙述已有结果及其意义，而不是把未知列成确定的功能缺陷。
4. 对未来预期给出任务、指标、可重复对照方法。
5. 不把“测试全部通过”偷换为“所有可想象任务全部完成”。
