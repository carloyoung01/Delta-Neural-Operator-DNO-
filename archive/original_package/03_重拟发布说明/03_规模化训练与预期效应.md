# DNO 规模化训练方向与预计可达效果（可验证研究计划）

## 研究核心

DNO 的后续潜力不能仅由数十条单元测试和几个小型合成任务判定，也不能用它不是标准 LLM 这件事限制它的可能表现。需要让它在适当任务、较大训练预算、不同输入形式、长时间交互与多模型对照下实际学习，再观察同一核心生成机制产生了什么效果。

## 六条重点预测

| 研究方向 | 为什么值得预计 | 预计会出现的可观察效果 | 验证数据、指标与对照 |
|---|---|---|---|
| 连续状态历史 | 历史通过当下有效状态影响后续；合成短历史已通过 | 在部分任务中，用较紧凑当前态代替逐事件全文回放；形成不同时间尺度的记忆性能曲线 | 延迟跨度10/100/1000与任务多样性；任务准确率、忘却率、状态内存；GRU/SSM/Transformer |
| 关系动态形成 | 关系生成后与普通承载体一样继续作用；反事实已看到关系影响后续行为 | 多对象交互中形成复用结构，可能表现出新关系发现、路径依赖以及随环境变化的组织方式 | 时变图、交互序列、世界模拟；结构预测、泛化、滚动误差；GNN/动态图模型/Transformer |
| 语言与动作流 | 统一计算核无固定语言词表，有当前状态与动作输入；合成寻址已能训练 | 在动作、停顿、修改、纠错、工具反馈等数据中探索与传统 token 序列不同的状态更新和响应策略 | 同一训练样本、参数预算、token/action 预处理对齐；准确率、效率、反馈适应性；小型LLM/SSM |
| 视频持续交互 | 视频天然包含多实体、变化、接触与时间反馈 | 时空结构在流中保持并调整；可能出现较好的长时交互预测或结构复用 | 视频动作、轨迹预测、遮挡交互；精度、长时漂移、延迟、显存；Video Transformer/SSM |
| 音频与连续信号 | 局部时间与状态演化适合探索逐段信号更新 | 对连续声音、重复模式、环境变化的在线状态建立不同于静态块处理的效果 | 音频分类/语音/声源分离；WER、F1、SI-SDR、延迟；Conformer/SSM |
| 多坐标研究/发现 | 同一状态的局部、整体、未来、关系坐标可能显露不同现象 | 大规模训练中出现难用单一数值汇总解释的结构差异；跨视角能给出更充分的现象描述 | 按身份追踪、因果干预、时延滚动、多种投影；跨观察一致性、误报和不可判定率 |

## 与 LLM 及其他模型对照的步骤（不预设谁赢）

1. **固定研究问题**：分别研究语言推理、动态关系、长期记忆、视频与音频，不将单一文本基准代表全领域。
2. **控制公平预算**：匹配训练 tokens/动作数据量、实际 FLOPs、GPU 小时、参数量、编码器和验证集；记录推理延迟、能量与显存。
3. **分阶段扩展**：小算力→中算力→更大算力，至少三个量级并重复随机种子；只根据实际可得算力安排，不预设最终规模。
4. **观察新的行为**：在预定义指标外，记录结构反复出现的现象，例如出现新关系类别、长期依赖、跨任务迁移、意料外结构模式。必须保存随机种子、环境、状态轨迹和反事实，以便独立重现。
5. **外部多视角检查**：先检查观察坐标、时间尺度、采样精度、身份、关系条件是否覆盖，若仍证据不足则标为未定，不立即修改冻结核心。
6. **形成可评价报告**：分开记录“实测有何变化”“是否相对于基线更好”“成本是否变化”“在哪些条件下成立”，而不是只报告单一胜率。

## 特别值得探索的意外效果

“意想不到”在科学研究中不是预先能保证的正向收益，而是**开放的、新观察到的、能够复现的差异化行为**。DNO 由于关系能够成为下一次作用的有效单元、当前条件能够改变下一步演化，因而可以合理期待在某些长期交互和多体数据中出现传统固定事件分类难以直接描述的行为模式。未来实验应同时对其有效性、可控性与成本作独立记录。

## 预计技术效益的可检验形式

- **计算利用率**：在相同精度下，比较无效寻址/作用次数、状态复用比例、任务每焦耳或每秒吞吐量。
- **泛化与关系结构**：在未见对象组合、变化边界与长期路径上测准确率、状态稳定性和迁移效果。
- **表达与观察**：比较仅使用全局指标与使用局部、时间、关系视角时，对失败模式及新关系的解释增益。
- **训练方法普适性**：在不同监督形式和模型配置下测梯度稳定性、不同随机种子和任务迁移。

**研究预期结论的性质：开放预测。** 更多算力和训练可能带来新的效果，也可能表明某种条件下应采用其他方法。任何方向都应以可重复测量决定，而不是由当前有限任务推出能力上限。
