# 从原始问题到当前封版：研究沿革与确认事项

## 原始研究问题

Delta 最初研究的不是“给 LLM 多加几个新功能”，而是让输入、反馈、当前状态、相互作用和环境变化构成递归生成；从过程中的变化、关系和选择性有效状态探索另一种底层计算基础。用户提出的动态结构、历史依赖、无限分支与最小有效变化属于**整体研究视角**，不应逐词转译成固定算法管理器。

## 研究演化与结果归类

1. **v0–v5探索**：逐步实验持续状态、历史保持、条件性作用、关系组合、无需强制接触、多候选和局部规则等可执行形式。历史版本保留为对照、反例和阶段性工具，不合并成正式模块堆栈。
2. **冻结压缩核心**：收敛到一个共享生成映射和统一当前状态，关系的作用结果回到当下结构；保留必要有限执行语义，不在核心内强制规定事件类别和观察分支。
3. **合成训练与回归**：双端寻址、一位延迟信息、数值图像/视频/音频/符号接口，展示可训练性、当前态作用和跨领域计算接口。
4. **独立观察研究**：局部/整体、当前/未来、值/关系、时间尺度、稳定身份等观察切换；发现旧 full 观察器身份信息漏检与浮点容差效应。
5. **当前重新整合**：生成核心与既有数据不变；发布叙述从“缺失模块/可能不能做”调整为“已证实的措施→具体作用→可检验的预计效果”，把未测试问题保留为开放研究空间。

## 已经确定的关键原则

- 状态承载有效历史后果，不强制积累事件文字日志。
- 当前关系可形成新结构，再参与后续作用；新发现应从可重复行为而非名称判断。
- 一个观察坐标的局限不应被自动判定为生成核心的缺陷。
- 观察仪器与核心独立；未发现差异时不自动宣布全部等价。
- 要扩大训练与比较，而不是因为未做大规模计算就声称模型具备固定能力上限。
- 任何性能、能耗或涌现主张必须落在可重现实验与合适的对照上。

这一份归纳只作为发行研究目录，不改变旧原始文档的字节，不将已有数学抽象重新定义为新的算法条款。
