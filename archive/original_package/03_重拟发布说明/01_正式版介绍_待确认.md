# DNO（Delta Neural Operator）正式研究版介绍（发布候选）

**状态：候选文案，拟公开发布前待最终核验。**

## 研究定位

**Delta Neural Operator（DNO）** 探索一种不同于单纯按 token 顺序计算的底层神经生成框架：系统由当前有效状态承载已经发生的作用结果，单元可以持续变化；实际交互能够更新原有状态、生成新的结构，而新结构又可以参与后续交互。模型通过一个共享的可训练生成映射，将独立演化、相互作用和关系再参与组织在统一计算过程中。

DNO 的目标不是直接替代某一个商业 LLM 产品，也不是为每一个未解释现象建立一个独立功能模块。它是可由不同研究者在语言、连续信号、动态关系、交互系统等任务上继续训练和研究的基础计算架构。

## 数学构想

DNO 的研究出发点是：**历史的有效结果进入当前结构，当前结构改变下一步可能发生的作用；多种局部观察可能呈现同一个持续生成过程的不同切面。**

在当前有限代码实现中，一个 DNO 状态承载各单元的有效内容、边界、局部规律、支撑、局部时间、连接与观察状态；真实发生的操作改变这些有效条件，改变未来可达的计算结果。由此形成一种无需完整事件日志也能在受控任务中保存有用历史信息的机制。

多坐标、多尺度观察属于**独立研究方法**：研究者可以对同一冻结核心分别研究局部与整体、当前与未来、内容与关系、不同时间步，而不是遇到一个难解释的观察就把新解释固化成内核模块。暂时无法解释意味着当前证据不足，并非自动证明模型没有相应潜力。

## 已核验成果

- 原正式发行核心在已定义的 **32项**行为测试中通过；研究所用多视角测试 **114项**、跨模态数值输入接口 **16项**通过，合计 **162/162**。
- 两组独立合成双端寻址训练在各自测试中均实现来源/目标识别 **100%**，结果均方误差约 **0.000274** / **0.000300**；控制实验表明查询条件影响结果。
- 两组合成一位历史任务模型在延迟 **3、7、15** 条件下的测试正确率均达到 **100%**，保存的检查点可重新加载并通过新的样本复核。
- 64个随机初始化的反事实观察在 **64/64** 情况下确认作用对当前后继状态留下有效差异；新关系存在时，其自身状态变化可改变后续寻址结果。
- 160种随机初始化的独立多视角压力测试显示，局部、规律、边界、连接和时间等视角可以区分部分全局汇总所遮蔽的差异。观察器身份标签覆盖缺口也被准确辨认并保留为研究证据。
- 同一核心已经通过图像块、视频时空块、声音频谱帧与符号向量的**数值接口可执行性测试**，表明基础运算无需绑定单一输入领域。

这些成果是完整、可重测的**已定义任务上的正向验证**。它们说明 DNO 的关键运算已能工作，并构成进一步训练和横向比较的技术基础；未纳入的开放任务不应被推断为已具备或不具备某种能力。

## 发展方向与预期效果

随着算力、训练样本、环境反馈、多任务基线和观察尺度扩大，DNO 值得重点探索的效果包括：

1. **动态结构学习**：单元与关系在连续作用中形成更有用的组合和长期有效结构。
2. **当前态承载历史**：在需要长期状态而非完整事件回放的任务中，形成具有任务效用的递归表示。
3. **多尺度可解释性**：不同坐标下出现不同可观察现象，减少把观察盲区误判为生成缺陷。
4. **跨输入领域的复用**：在文本、图像、视频、声音或具身交互中探索同一基础计算框架的不同训练结果。
5. **与其他架构形成新互补**：与 LLM、Transformer、RNN/GRU、SSM 等相同预算对比，研究精度、长期稳定性、状态复用、计算开销和结构泛化。
6. **涌现性与差异化现象**：更长时间、更复杂环境、更多交互路径可能出现当前小规模评测没有预先覆盖的行为模式，应建立可记录、可复现的开放观察机制。

上述是**预期研究方向，不是预先承诺全部实现，也不是对其他模型的胜负声明**。恰恰因为目前的实验规模有限，下一阶段应通过较大训练规模和多种对照真实测量其潜在上限和新现象。

## 最终原则

**以全部已通过的受控测试为证据起点，以更多训练与多模型对照为扩展路径，以开放的多坐标观察辨认新现象；冻结 DNO 生成核心，不把观察仪器误当成内核。**
