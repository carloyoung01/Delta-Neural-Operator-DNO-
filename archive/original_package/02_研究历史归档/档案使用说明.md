# 历史研究归档：保留探索，不叠加到 DNO 核心

本目录收录此前存在于研究环境中的阶段性代码、数学讨论、对照实验、反例、三坐标问题向位图及封存版本。
这些 ZIP **原样复制**，都有 SHA-256 和内部 ZIP CRC 验证；其内部文件是历史阶段的记录，可能存在不同实现、不同试验目标、结果不一致的对照模型。

最终可运行 DNO 核心只以 `../01_正式源码_冻结核心/dno.py` 为准；不得把这些阶段性实现拼接为新的主生成算法。

研究材料中的更早文案保留原貌作为可核查史料，不应将其中的旧结论直接作为新的宣传文案。用于公开发表的主张，以 `../03_重拟发布说明/` 和实时复核结果为准。

如需复核某一历史发现，请先指明对应档案、训练预算、基线和指标；历史资料的完整保存不代表所有历史假设都被证明。
